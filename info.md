# Earthquake Monitor (INGV + USGS)

Real-time earthquakes from **INGV** and **USGS** in Home Assistant: sensors,
alert binary sensor, `geo_location` entities, a `earthquake_monitor_quake`
event for notifications, a notification blueprint and a **Leaflet map card**
(auto-registered) with CARTO / OpenStreetMap tiles.

Terremoti in tempo reale da **INGV** e **USGS** in Home Assistant: sensori,
sensore di allerta, entità `geo_location`, evento `earthquake_monitor_quake`
per le notifiche, blueprint di notifica e **scheda mappa Leaflet**
(registrata automaticamente) con tile CARTO / OpenStreetMap.

⚠️ Not an early-warning system / Non è un sistema di allarme sismico.

Data: INGV FDSN (CC BY 4.0) · USGS GeoJSON (public domain).
